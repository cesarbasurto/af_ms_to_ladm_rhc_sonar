# ETL OTL de Rondas hídricas acotadas.
ETL para airflow que transforma los datos del modelo simplificado de rondas hídricas al modelo extendio LADM_COL de rondas hídricas.


```
.
├── config
│   └── etl_config
│       └── ms_to_ladm_rhc
├── dags
│   └── ms_to_ladm_rhc
├── logic
│   └── ms_to_ladm_rhc
│       └── sql
│       └── resources
└── output
    └── ms_to_ladm_rhc
```
